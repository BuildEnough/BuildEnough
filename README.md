# BuildEnough

Java / Spring 기반 웹 백엔드 개발을 중심으로 공부하고 프로젝트를 만들고 있습니다.  
단순히 기능을 붙이는 것보다, 데이터 흐름, DB 설계, 비즈니스 로직, 사용자 흐름을 이해하면서 실제로 동작하는 서비스를 만드는 데 관심이 있습니다.
